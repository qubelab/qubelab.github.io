MODEL / ASSUMPTIONS

The initial state is |00⟩ (or |0⟩), and all gates are unitary. Free delays use H/h = ΔνA Iz + ΔνB Sz + J IzSz. For a pure two-qubit state, concurrence = √(1 − |rA|²); single-spin reduced states need not be pure. CNOT uses the selected spin as control; SWAP and CZ act on both spins.

Educational implementation; validate against a dedicated spin dynamics package before using results for quantitative experimental analysis.
